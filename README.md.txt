# Vertigo Wheel Demo

Unity wheel of fortune demo project.

## Features
- Normal, safe (every 5th zone), and super zones (every 30th zone)
- Bomb and revive system
- Reward reveal effect
- Horizontal reward collection popup
- Spin, reward, collect, and bomb audio empty fields that can be filled in request
- Responsive UI for multiple aspect ratios
